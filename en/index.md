# Utsushi PDF

A macOS app that batch-converts Word, Excel, PowerPoint, Pages, Keynote and Numbers
files into **individual** PDFs by drag and drop (one file in, one PDF out — files are
never merged).

**Your files never leave your Mac.** Conversion happens entirely on-device.

## What it does

- Converts Word, Excel, PowerPoint, Pages, Keynote and Numbers files to PDF
- Turns an image straight into a single-page PDF
- Converts many files at once
- Lets you choose where PDFs go: next to the original, or a folder you pick
- Never overwrites an existing file with the same name — it saves alongside it with a number instead

## Requirements

macOS 14.0 or later. Works on both Apple silicon and Intel Macs.
