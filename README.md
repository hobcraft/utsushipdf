# utsushipdf（公開ページ用）

Utsushi PDF（macOS アプリ）のサポートとプライバシーポリシー。
GitHub Pages で `https://hobcraft.github.io/utsushipdf/` に公開する。

- サポート: `https://hobcraft.github.io/utsushipdf/support/`
- プライバシーポリシー: `https://hobcraft.github.io/utsushipdf/privacy/`

**このリポジトリは公開される。アプリのソースや申請メモを入れないこと。**
ソースと内部資料は `~/Projects/utsushi-pdf/`（非公開）にある。SeiriBox と同じ構成。

## 公開の手順（済み）

`hobcraft/utsushipdf`（public）に push 済み。

GitHub の Settings → Pages で Source を `main` / `/ (root)` にする（未実施ならここだけ残作業）。
公開まで数分かかる。

公開したら、2つの URL をブラウザで開いて表示されることを確認する（404 だと審査で落ちる）。
